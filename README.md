# MDstash

> **Your markdown files, stashed, sorted, and ready to drop anywhere.**  
> *Nothing ever leaves your device.*

MDstash is a craft-inspired, local-first organizer for Markdown files and AI prompts. Designed for developers and AI-tool power users who frequently reference `CLAUDE.md`, `AGENTS.md`, `README`s, cursor rules, and context prompts.

---

## ✨ Features

- 📁 **Instant Drag-and-Drop Import:** Drop files (`.md`, `.markdown`, `.txt`) or entire directories straight into your browser.
- 🗂️ **Collections & Tags:** Color-coded collections and flexible tags to organize your knowledge.
- 📋 **Copy Modes:** One-click copy in **Raw**, **Fenced Code Block**, or **Prompt-Ready** (`### File: <name>`) formats.
- 📦 **Bundle Multi-Select:** Select multiple files and copy them as a unified prompt block for AI chats.
- 🔍 **Fast Fuzzy Search:** Powered by local [MiniSearch](https://github.com/lucaong/minisearch) indexing over title, filename, tags, and content.
- 📜 **Version History:** Automatic non-destructive snapshots on edit, with restore capability.
- 💾 **Export & Import:** Export your entire stash as a `.zip` archive containing real `.md` files and a portable `manifest.json`.
- 🔒 **Zero Cloud & Private:** IndexedDB storage with persistent storage request support (`navigator.storage.persist`). No telemetry, no accounts.
- ⚡ **Offline & Installable (PWA):** Works everywhere, even with no internet connection.

---

## 🎨 Design System

MDstash features a warm, craft retro aesthetic:
- **Palette:** Sage `#6B7B6E`, Forest `#2F3A33`, Cream `#F5F2E3`, and Dusty Pink `#C99AB5` accent.
- **Typography:** Chunky condensed display typography, friendly rounded UI, and crisp monospace preview.
- **Feel:** Subtle analog grain texture and tactile stamp-like badges.
